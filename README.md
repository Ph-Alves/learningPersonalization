# learningPersonalization

Repo de estudos focado em personalização de apps iOS — temas, ícones alternativos e animações.

## Tópicos abordados

- **Temas** — suporte a modo claro/escuro e temas customizados
- **Ícones alternativos** — troca dinâmica de ícone do app em runtime
- **Animações** — animações de UI com SwiftUI e UIKit

## Requisitos

- Xcode 15+
- iOS 17+
- Swift 5.9+

## Como rodar

```bash
git clone https://github.com/Ph-Alves/learningPersonalization.git
cd learningPersonalization
open *.xcodeproj  # ou *.xcworkspace se usar CocoaPods/SPM
```
